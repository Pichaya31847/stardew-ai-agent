# เครื่องมือ

**ภาษาไทย** · [English](tools.md) · [← README](../README.md)

เครื่องมือทั้งหมดที่ AI เรียกใช้ได้ แยกตามงาน MCP endpoint ของ farmer ทุกคน (`/mcp`, `/mcp/p1` … `/mcp/p3`) มีครบทุกตัว

- ⚡ = ไม่เสียเวลาในเกม (แค่อ่านข้อมูลเกม หรือเป็นการพูดคุย) เครื่องมืออื่นทั้งหมดคือ **action** ที่ใช้เวลาในเกม ทำได้ทีละอย่างต่อ farmer
  และต้องใส่ `reason` (เหตุผลที่คนดูเห็นบน overlay ไม่ได้เขียนไว้ในตารางด้านล่าง)
- argument ที่เป็น*ตัวเอียง*ไม่บังคับใส่
- ตัวนิยามเครื่องมืออยู่ในไฟล์ชั้นบนสุดของ [`mod/StardewMCP/Agent/`](../mod/StardewMCP/Agent/) ส่วนหน้าตาผลลัพธ์ดูได้ที่
  [HTTP API → Tool results](api.md#tool-results) (อังกฤษ)

## ดูรอบตัวและคิด

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `status` ⚡ | | วัน เวลา อากาศ (และของพรุ่งนี้) ดวง สถานที่ พลังงาน เงิน ของที่ถือ ของที่สวมอยู่ ตัวเลือกที่ค้างอยู่ และหน้าต่างบทสนทนาหรือเมนูที่เปิดอยู่ |
| `look` ⚡ | *`radius`*, *`kinds`*, *`diff`* | แผนที่รอบตัวแบบช่อง (ค่าเริ่มต้น 17×17 รัศมี 8) พร้อมคำอธิบายสัญลักษณ์และรายการสิ่งของที่เห็น รวมถึงผู้เล่นคนอื่น `kinds` (เช่น `["crops","debris"]`) กรองรายการ `diff=true` แสดงเฉพาะช่องที่เปลี่ยนไปจากครั้งก่อน |
| `inventory` ⚡ | | ของในกระเป๋า ของที่สวมอยู่ และของที่ติดคันเบ็ด |
| `farm_summary` ⚡ | | รายงานทั้งฟาร์ม: ดินที่ไถแล้วแต่ยังว่าง ผักแต่ละชนิดกับจำนวนวันที่เหลือ ต้นที่ยังไม่รดน้ำ ต้นที่สุกแล้ว ต้นที่ตาย ต้นที่โตไม่ทันฤดู ของป่า เศษไม้หิน บัวรดน้ำ และแหล่งน้ำที่ใกล้ที่สุด |
| `think` ⚡ | `text` | ความคิดส่วนตัว ขึ้นบน overlay ไม่มีใครในเกมเห็น ถ้ามีตัวอักษรจีนปนมา จะถูกตีกลับให้เขียนใหม่เป็นภาษาที่ตั้งไว้ |

## เดินทาง

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `walk_to` | `x`, `y` | หาทางเดินไปยังช่องที่กำหนดในแผนที่ปัจจุบัน ถ้าช่องนั้นไปไม่ถึงจะหยุดที่ช่องใกล้สุดที่ไปถึงได้ (partial) ในฟาร์มและ Backwoods ถ้าทางถูกวัชพืช หิน หรือกิ่งไม้ปิดไว้ไม่เกิน 15 ช่อง จะถางทางให้ระหว่างเดิน (ไม่ตัดต้นไม้อ่อน) แล้วบอกในผลลัพธ์ว่าถางไปกี่ช่องและใช้แรงไปเท่าไร ถ้าเดินชนประตูที่ล็อกอยู่จะหยุดเดินทันที |
| `travel_to` | `location` | ไปแผนที่อื่น ใส่ชื่อเจ้าของร้าน ชาวเมือง หรือเพื่อนฟาร์มเมอร์ก็ได้ ถ้าประตูปิดจะบอกว่าเปิดกี่โมง ถ้าอยู่ในงานเทศกาลจะออกจากงานก่อน เวลาเล่นหลายคน เกมให้เข้างานเทศกาลได้เฉพาะตอนที่ไปพร้อมกันทุกคน จึงรอคนอื่นได้นานสุดหนึ่งนาที (และบอกให้เขารู้) ถ้าไม่มาก็ยกเลิกแล้วแจ้ง `not_ready` แทนที่จะค้างอยู่ในกล่องรอ |
| `mount`, `dismount` | | ขี่ม้า (ต้องมีคอกม้า) และลงจากม้า |

## ทำฟาร์ม

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `use_tool` | `tool`, `tiles`, *`max_hits`* | ใช้เครื่องมือกับช่องเดียวหรือหลายช่อง (จอบ บัวรดน้ำ ขวาน อีเต้อ เคียว...) ถ้าบัวรดน้ำหมดจะไปเติมที่แหล่งน้ำใกล้สุดที่ไปถึงได้ก่อน |
| `plant` | `item`, *`tiles`* หรือ *`area`* | ปลูกเมล็ดหรือใส่ปุ๋ยบนดินที่ไถแล้ว: ระบุช่อง ระบุพื้นที่ `[x, y, w, h]` หรือไม่ระบุเลย = ทุกช่องที่ไถแล้วและยังว่างของเรา (หรือของที่ไม่มีเจ้าของ) ในแผนที่ ดินที่ฟาร์มเมอร์คนอื่นไถหรือปลูกไว้จะไม่แตะ |
| `harvest` | `tiles` | เก็บผักหรือของป่าในช่องที่ระบุ |
| `water_all` | *`whose`* | รดน้ำทุกต้นที่ยังแห้งในแผนที่ (`whose: "mine"` = เฉพาะของตัวเอง) เติมน้ำที่แหล่งน้ำใกล้สุดที่เดินไปถึงได้เอง และบอกว่ารดของใครไปบ้าง วันที่ 28 จะข้ามต้นที่จะตายตอนเปลี่ยนฤดู |
| `harvest_all` | *`whose`* | เก็บผักที่สุกแล้วของตัวเองและของป่าทั้งแผนที่ ผักที่ชาวไร่คนอื่นปลูกจะเว้นไว้ให้เจ้าของ เว้นแต่ใส่ `whose=all` |
| `forage` | *`places`*, *`max_places`*, *`list`* | เดินไปแผนที่รอบฟาร์มที่วันนี้มีของป่า เริ่มจากที่ใกล้ที่สุด แล้วเก็บให้หมด `list=true` แค่นับจำนวน |
| `clear_area` | `x`, `y`, `w`, `h` | เคลียร์พื้นที่สี่เหลี่ยมด้วยเครื่องมือที่เหมาะ ไล่ทีละแถวจากฝั่งที่ใกล้ตัว เคียวตัดพืชที่ตายแล้วออกด้วย ตอไม้ใหญ่และหินก้อนใหญ่จะข้ามและแจ้งให้รู้ ถ้าเกิน 100 ช่องจะทำแถวบนก่อน แล้วบอกคำสั่งสำหรับส่วนที่เหลือ |
| `till_area` | `x`, `y`, `w`, `h` | เคลียร์แล้วไถพื้นที่สี่เหลี่ยมทีละแถว แต่ไถเท่าที่มีเมล็ดของฤดูนี้ (หักดินที่ไถแล้วแต่ยังว่างออก) ถ้าไม่มีเมล็ดจะไม่ไถให้ |
| `place` | `item`, `tiles` | วางของ เครื่องจักร หีบ สปริงเกอร์ รั้ว หรือเฟอร์นิเจอร์ลงบนพื้น ถ้าติดตั้ง Automate ไว้ เวลาวางเครื่องจักรจะบอกว่าเครื่องนั้นทำอะไรจากอะไร และให้วางหีบติดกับมัน ส่วนหีบที่วางติดเครื่องจะบอกว่ารับได้เฉพาะวัตถุดิบของเครื่องนั้น |

เครื่องมือแบบทำทีละหลายช่อง (`water_all`, `harvest_all`, `clear_area`, `till_area`, `plant` แบบพื้นที่) จะหยุดพร้อมบอกเหตุผล
(พลังงานต่ำ มีเมนูเปิด ดึกแล้ว กระเป๋าเต็ม) และบอกว่าเหลืออีกเท่าไร ส่วน `use_tool`, `plant` และ `harvest` จะรายงานจำนวนช่อง
`done`, `remaining` และ `skipped` เสมอ ถ้าช่องไหนต้องใช้เครื่องมืออื่นจะบอกให้ด้วย (เช่น "it is twig: use the Axe") รายการช่องรับรูปแบบที่โมเดลเล็กชอบส่งมาด้วย เช่น `[{"x":1,"y":2}]`, `["1,2"]`,
ข้อความเดียว `"[(1, 2), (3, 4)]"`, ตัวเลขเรียงกัน `[1, 2, 3, 4]` หรือช่องเดียวเป็น `tile` หรือ `x`/`y`

## ความรู้ในเกม ⚡

อ่านจากข้อมูลของเกมเอง ไม่เสียเวลาในเกม

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `crops` ⚡ | *`season`* | วางแผนปลูกตามฤดู: วันที่ใช้โตและโตซ้ำ วันสุดท้ายที่ยังปลูกทัน จำนวนรอบเก็บที่ทัน ราคาเมล็ดและราคาขาย ทองต่อช่องต่อวัน และบอกว่าเมล็ดไหนมีติดตัว |
| `item_info` ⚡ | `name` | ราคาขายแยกตามคุณภาพ ฟื้นพลังได้เท่าไร ร้านที่ขาย และสูตรที่ใช้ของชิ้นนี้ |
| `fish_guide` ⚡ | *`name`*, *`season`* | ปลาแต่ละชนิดกินเบ็ดที่ไหน อ่านจากข้อมูลของเกมเอง ทั้งแผนที่ ฤดู ช่วงเวลา สภาพอากาศ เลเวลตกปลาที่ต้องมี และบอกว่าตัวไหนยังไม่เคยตกได้ ถ้าไม่ใส่ชื่อจะได้รายชื่อปลาที่ยังตกได้วันนี้แยกตามแผนที่ พร้อมปลาตำนานทุกตัวและจุดที่ต้องเหวี่ยงเบ็ดลงไป ถ้าใส่ชื่อจะได้ทุกแหล่งของปลาตัวนั้น และบอกว่าวันนี้ตกได้หรือเปล่า |
| `calendar` ⚡ | *`days`* | วันนี้และวันถัดไป: เทศกาล วันเกิด เทศกาลครั้งหน้า เวลาเปิดปิดและวันหยุดของร้านหลัก |
| `villagers` ⚡ | *`name`* | ชาวเมืองทุกคน: อยู่ที่ไหน หัวใจกี่ดวง วันนี้และสัปดาห์นี้คุยหรือให้ของแล้วหรือยัง วันเกิด ถ้าใส่ชื่อจะบอกของที่เขาชอบเท่าที่รู้แล้ว และสิ่งที่ยังขาดก่อนขอเดตหรือขอแต่งงาน |
| `quests` | `action?`, `quest?`, `reason?` | ไม่ระบุ action หรือใช้ `list` เพื่ออ่านสมุดเควสต์ บอร์ด และ Special Orders ทันที รวมเงินรางวัลที่ยังไม่รับ ใช้ `claim_reward` เพื่อเปิดสมุดและกดรับรางวัล โดย `quest` คือชื่อเควสต์ตรงตามรายการ (ไม่ระบุจะรับรายการแรก) การรับรางวัลต้องระบุ reason และปิดเมนูอื่นก่อน ทุกเควสต์มีบรรทัด "How:" บอกว่าต้องเอาอะไรไปให้ใคร และตอนนี้มีติดตัวเท่าไร ส่วนบรรทัด Community Center บอกขั้นต่อไปของเนื้อเรื่อง |

## ของ คราฟต์ และทำอาหาร

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `craft` | *`recipe`*, *`quantity`* | คราฟต์จากสูตรที่รู้ `craft()` แสดงสูตรทั้งหมดพร้อมบอกว่าของที่มีประโยชน์เอาไว้ทำอะไร (หุ่นไล่กา สปริงเกลอร์ ปุ๋ย เครื่องจักร) และสูตรดี ๆ ที่ยังไม่รู้ว่าปลดล็อกได้อย่างไร ถ้าของที่ขาดอยู่ในหีบของตัวเอง จะเดินไปหยิบมาให้ก่อน ถ้ายังไม่พอจะบอกว่ามีอยู่เท่าไรจากที่ต้องใช้และหาส่วนที่ขาดได้จากที่ไหน และถ้าสั่งคราฟต์ของเดิมซ้ำโดยที่ของในกระเป๋ายังไม่เปลี่ยน จะปฏิเสธทันที |
| `cook` | *`recipe`*, *`quantity`* | ทำอาหารที่รู้สูตรในครัวบ้าน ใช้วัตถุดิบจากกระเป๋าและตู้เย็น `cook()` แสดงสูตรทั้งหมด |
| `machine` | *`action`*, *`item`*, *`quantity`* | ใช้เครื่องจักรตรงที่ยืนอยู่ (เตาหลอม ถังหมัก โหลดอง เครื่องทำชีส เครื่องทำมายองเนส เครื่องทอผ้า เครื่องทำน้ำมัน...) `list` บอกว่าแต่ละเครื่องทำอะไรและเสร็จเมื่อไร รวมถึงเครื่องที่เสร็จแล้วในจุดอื่นของฟาร์ม `load` เดินไปใส่ของในทุกเครื่องที่ว่างและรับของชิ้นนั้น เชื้อเพลิงอย่างถ่านหินหยิบจากกระเป๋าให้เอง `collect` เก็บของที่เสร็จแล้วทั้งหมด |
| `goals` ⚡ | *`area`* | เป้าหมายของทั้ง run คือ achievement ทุกอัน ยกเว้นสาย Joja พร้อมความคืบหน้าของฟาร์มเมอร์คนนี้ที่อ่านจากเกมเอง `area` เลือกได้: summary (ค่าเริ่มต้น), shipping (ของที่ยังไม่เคยส่งขาย), cooking (เมนูที่ยังไม่เคยทำ และวิธีได้สูตรแต่ละเมนู), crafting, fish, museum, friends, monsters (เป้าหมายล่ามอนสเตอร์ของ Marlon), upgrades, family |
| `upgrade_tool` | *`tool`* | เดินไปหา Clint แล้วสั่งอัปเกรดเครื่องมือ (ขวาน อีเต้อ จอบ บัวรดน้ำ ถังขยะ) ผ่านร้านอัปเกรดของเขา ถ้าไม่ใส่ชื่อจะแสดงรายการที่อัปเกรดได้ หรือไปรับของที่อัปเกรดเสร็จแล้ว |
| `chest` | *`x`*, *`y`*, *`action`*, *`item`*, *`items`*, *`quality`*, *`quantity`* | เก็บหรือหยิบของในหีบหรือตู้เย็นในครั้งเดียว: ตามชื่อและคุณภาพ หลายชิ้นพร้อมกัน หรือ "ทั้งหมด" หีบทุกใบใช้ร่วมกัน ใครจะใส่หรือหยิบก็ได้ และทุกครั้งจะถูกบันทึกไว้ `action=all` แสดงหีบและตู้เย็นทุกใบในฟาร์มพร้อมของข้างใน และใครใส่หรือหยิบอะไรไปล่าสุด โดยไม่ต้องเดินไป ถ้าไม่ใส่ `x`/`y` จะใช้หีบที่เปิดอยู่ หรือหีบที่ใกล้ที่สุดในแผนที่ (หีบของตัวเองก่อน) ผลลัพธ์จะบอกด้วยว่าตั้งแต่ใช้หีบนั้นครั้งล่าสุด คนอื่นใส่หรือหยิบอะไรไปบ้าง ถ้าใส่ `x`/`y` แต่ไม่มีหีบตรงนั้นในแผนที่นี้ แต่มีหีบที่ช่องเดียวกันในบ้าน (หรือในฟาร์ม) จะเดินไปที่นั่นก่อน ผลผลิตที่ขายได้ (ผัก ดอกไม้ ของป่า ปลา ของจากสัตว์และของแปรรูป) จะเก็บเข้าหีบเท่าที่ bundle หรือเควสต์ยังต้องใช้ ที่เหลืออยู่ในกระเป๋าไว้ส่งขาย |
| `equip` | `item`, *`slot`*, *`count`* | สวมแหวน รองเท้า หรือหมวก (ของเดิมกลับเข้ากระเป๋า) หรือติดเหยื่อและอุปกรณ์เข้าคันเบ็ด |
| `wear` | `item` | ใส่หมวก เสื้อ หรือกางเกงจากกระเป๋า |

| `journal` ⚡ | `diary`, `lessons`, `plan`, *`notes`*, *`self`*, *`people`*, *`day`* | ความจำข้ามวันของ AI: ไดอารี่ให้คนดูอ่าน บทเรียน (ต่อท้าย) แผนแบ่งเป็น ฤดู / สัปดาห์ / วันนี้ ข้อเท็จจริงเพิ่มเติม บันทึก `self` (ตัวเองเป็นใคร เขียนทับทุกเย็น) และ `people` หนึ่งบรรทัดต่อเพื่อนร่วมฟาร์มแต่ละคน `day` ใช้เขียนย้อนวันที่พลาดไป ถ้าไดอารี่มีตัวอักษรจีนปนมา จะถูกตีกลับให้เขียนใหม่เป็นภาษาที่ตั้งไว้ |
| `go_to_bed` | | จบวัน จะไม่ยอมนอนจนกว่าจะเขียน `journal` ของวันนี้ เหตุการณ์ตอนกลางคืนจะกลับมาเป็นบรรทัด `Overnight:` ถ้าสั่งนอนเร็วเกินไป (ก่อน 17:00 และแรงยังเหลือเกินหนึ่งในสี่) จะบอกงานหนึ่งอย่างที่ควรทำตอนนี้พร้อมคำสั่งที่เรียกได้ทันที และบอกว่านอนได้เมื่อไร ถ้าสั่งซ้ำในวันเดียวกันจะตอบสั้น ๆ บรรทัดเดียว ถ้าหมดแรงก่อน 18:00 ตอนเล่นหลายคนจะแนะนำให้ `rest` หนึ่งครั้ง (สั่งซ้ำจะนอนจริง) |
| `morning_chores` | | งานต้นวันในครั้งเดียว: เปิดกล่องของขวัญในบ้าน อ่านจดหมายในตู้ทุกฉบับ (รับของแนบและเควสต์) รับเงินจากเควสต์ที่ทำเสร็จ ปลูกเมล็ดพืชของฤดูนี้ที่พกอยู่ลงดินของเราที่ไถแล้วแต่ยังว่าง (เมล็ดที่โตไม่ทันก่อนหมดฤดูจะข้ามพร้อมบอกชื่อ และวันที่ 28 จะไม่ปลูกเลย) บอกว่ามีผลผลิตที่ควรขายค้างอยู่ในกล่อง แปลงที่ยังไม่มีหุ่นไล่กา และของมีประโยชน์ที่คราฟต์ได้ตอนนี้ แล้วส่งข้อความในจดหมายกลับมาให้อ่าน |

## เล่นด้วยกัน (จอแบ่ง)

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `say` ⚡ | `text` | พูด: ขึ้นในกล่องแชตและเหนือหัว ได้ยินเฉพาะผู้เล่นที่จอเห็นเรา `@ชื่อ` ใช้เรียกให้อีกคนหันมาฟัง ถ้ามีตัวอักษรจีนปนมา จะถูกตีกลับให้พูดใหม่เป็นภาษาที่ตั้งไว้ |
| `emote` ⚡ | `name` | แสดงอีโมตเหนือหัว |
| `give` ⚡ | `to`, `item`, *`count`* | ยื่นของให้ผู้เล่นที่อยู่ใกล้ |
| `pay` ⚡ | `to`, `amount` | โอนเงิน (ดู *ร้านค้าและเงิน*) |
| `propose` | `to` | ขอผู้เล่นอีกคนแต่งงาน |
| `answer_proposal` | `accept` | ตอบคำขอแต่งงานของผู้เล่นอีกคน |

farmer แต่ละคนเห็นกันแค่ไหน: `look` และ `status` แสดงผู้เล่นคนอื่นที่อยู่ในจอ พร้อมเครื่องมือที่เขา *กำลังใช้จริง* เหตุผล และใช้ไปนานเท่าไร
เทียบกับประโยคล่าสุดที่เราได้ยินเขาพูด ส่วน @ชื่อ การได้ของ ผู้เล่นเดินเข้ามาในจอหรือเข้าบ้านเรา ของในหีบหรือแปลงเราถูกหยิบ
ฝนเริ่มตก หรือมีกาลงฟาร์ม จะกลับมาเป็น `Events:` ในผลลัพธ์ถัดไป และหยุด `wait`, `walk_to`, `travel_to` หรือการทำฟาร์มที่ทำค้างอยู่

## สำหรับสคริปต์

| เครื่องมือ | Argument | ทำอะไร |
|---|---|---|
| `relationships_report` ⚡ | | ข้อมูลความสัมพันธ์ของ farmer คนนี้เป็น JSON ไว้ให้สคริปต์ใช้ (เหมือน [`/api/relationships`](api.md#endpoints) แต่เฉพาะที่นั่งเดียว) |

คำแนะนำร้านค้า: travel_to ยังหยุดเมื่อเข้าอาคาร แต่จะแสดงพิกัดแอ็กชันร้านที่อยู่ในระยะ 20 ช่อง ไม่เกินแปดจุด รวมถึงเมื่อ interact ขาดพิกัดหรือยังไม่เปิดร้าน ต้องส่งทั้ง x และ y ของเคาน์เตอร์ให้ interact ซึ่งจะเดินไปยืนข้างเป้าหมายแล้วกดให้ เมื่ออยู่ในร้าน shop_list, buy และ sell จะเปิดเคาน์เตอร์ให้เอง (เดินไปกด หรือเปิดร้านแบบที่เกมทำเมื่อเจ้าของร้านอยู่) และไม่ซื้อขายเกินที่สั่ง
